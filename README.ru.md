> [!IMPORTANT]
> **Переход на 0.6 с 0.5 и более ранних версий: один шаг вручную, один раз.**
>
> **Зачем.** До 0.5 в `compose.yaml` была записана точная версия приложения, поэтому для
> каждого обновления нужен был ещё и `git pull`. С 0.6 `compose.yaml` следует за мажорной
> версией и берёт все настройки из `.env`: он больше не меняется, и любое следующее
> обновление — это только `docker compose pull` и `docker compose up -d`.
>
> **Как.** В папке приложения; ваш `.env` и данные остаются как есть.
>
> Без воркера:
>
> ```sh
> curl -L -o compose.yaml https://github.com/Ivamic/immich-steward/releases/latest/download/compose.yaml
> docker compose pull
> docker compose up -d
> ```
>
> С воркером на сервере:
>
> ```sh
> curl -L -o compose.yaml https://github.com/Ivamic/immich-steward/releases/latest/download/compose.yaml
> docker compose --profile worker pull
> docker compose --profile worker up -d
> ```
>
> Если в `.env` есть строка `STEWARD_VERSION=…`, сначала удалите её: она оставит старую версию. [Подробнее](docs/updating.md#coming-from-05-or-older) (на английском).

> **Статус: идёт активная разработка.** Ранняя версия: уже работают разбор фото без места,
> подсказки по фото, снятым близко по времени, GeoCLIP и похожие фото вашей собственной
> библиотеки; остальные модули ещё впереди. Возможны ошибки и изменения между версиями. Прежде
> чем записывать места в Immich, сделайте резервную копию библиотеки.

Приложение-компаньон для [Immich](https://immich.app), которое ставится у вас на сервере. Для
каждого фото без места несколько модулей — фото, снятые незадолго до и после, нейросеть
GeoCLIP и похожие фото того же места из вашей же библиотеки — предлагают, где оно снято,
и всё это на одной карте. Вы выбираете щелчком или клавишей, а можно указать место сразу
для многих фото. В Immich ничего не записывается, пока вы этого не сделаете, и любое
изменение можно отменить.

Типичный случай: семейный фотоархив со сканами отпечатков, фото со старых цифровых камер без
GPS или из мессенджеров, где метаданные потерялись.

## Идея

Приложение объединяет несколько независимых **модулей определения места**. Каждый модуль
предлагает одно или несколько мест, и все они показываются вместе на карте: цвет обозначает
модуль, номер — место в рейтинге. Вы просматриваете их, выбираете одно или ставите точку
вручную.

Доступные модули:

- **Соседи по времени** — фото, снятые незадолго до и сразу после, у которых место уже есть.
  Маршрут между ними рисуется на карте с окраской по времени; камеры с неверными часами можно
  исключить или оставить только камеру этого фото.
- **GeoCLIP** *(необязательный воркер)* — нейросеть определяет место по снимку в любой точке
  мира, локально на процессоре сервера или на видеокарте другого компьютера. Подсказки
  показываются с уверенностью, в галерее есть фильтр уверенных догадок. Модуль может смотреть и
  только на часть фото: здание за толпой, вывеску, гору на горизонте.
- **Похожие фото** *(необязательный воркер)* — фото того же места из вашей собственной
  библиотеки, у которых место есть: та же улица, дом, вид или комната, с другого ракурса или в
  другое время года. Работает на [MegaLoc](https://github.com/gmberton/MegaLoc), модели для
  узнавания мест; на настоящей семейной библиотеке около половины её подсказок верны с
  точностью до 1 км, а из уверенных — больше восьми из десяти. Поиск всегда учитывает места,
  которые вы успели поставить.

Фото можно повернуть в приложении, чтобы лучше рассмотреть, модули работают с повёрнутым фото,
а поворот можно сохранить в Immich.

Чтобы проверить место глазами, под картой можно показать спутниковые снимки: Sentinel-2 от EOX
(без ключа), Esri World Imagery или MapTiler Satellite (со своим ключом). Все они выключены,
пока вы не включите один из них.

В планах:

- **Уличные панорамы** на карте, чтобы проверить место глазами.
- **Геометрическая проверка** похожих фото (совпадение деталей, а не только общего вида) и
  распознавание фото, на которых места нет вовсе: крупные портреты, животные, растения, предметы.
- **Рассуждение LLM** (в духе Img2Loc) — модель, понимающая изображения, рассуждает над фото и
  уликами, собранными другими модулями.
- **Внешние сервисы** — необязательные облачные распознаватели, по модулю на сервис.

Новые модули можно будет добавлять как плагины.

## Принципы

- **Ничего не записывается в Immich автоматически.** Координаты отправляются только после того,
  как вы подтвердили место. Любое изменение можно отменить.
- **Сначала локально.** Модули по умолчанию работают на вашем оборудовании. Модули, которые
  отправляют изображения сторонним сервисам, никогда не запускаются автоматически — только по
  явной просьбе и с ясным предупреждением, что и куда уходит.
- **Поиск по области.** Если снимок целиком сбивает с толку (например, толпа перед памятником),
  выделите часть изображения и запустите определение только на ней.
- **Отметка «Место неприменимо».** Отметьте фото, для которых место не имеет смысла, и они больше
  не появятся в списке дел.

## Установка

Steward запускается через Docker Compose рядом с вашим сервером Immich (Immich v3.x):

```sh
mkdir immich-steward && cd immich-steward
curl -L -o compose.yaml https://github.com/Ivamic/immich-steward/releases/latest/download/compose.yaml
curl -L -o example.env https://github.com/Ivamic/immich-steward/releases/latest/download/example.env
cp example.env .env      # задайте STEWARD_IMMICH_URL, STEWARD_SECRET_KEY и DB_PASSWORD
docker compose up -d
```

Образы скачиваются из GitHub Container Registry (`ghcr.io/ivamic/immich-steward-core`, `amd64` и
`arm64`); их можно и
[собрать из исходников](docs/updating.md#building-the-images-from-source). Обновление:
`docker compose pull && docker compose up -d`.

Затем откройте `http://<ваш-сервер>:8780` и войдите с учётной записью Immich.

GeoCLIP и похожие фото работают в необязательном контейнере воркера (2–4 ГБ памяти, когда
загружены обе модели): задайте `STEWARD_WORKER_TOKEN` в `.env` и запустите
`docker compose --profile worker up -d`.
Воркеры могут работать и на других компьютерах вашей сети
([как](docs/workers.md#a-worker-on-another-computer)).
